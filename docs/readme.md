# LeetCode 學習筆記

從目前的解法出發，理解為什麼可行，再用測試檢查推理。筆記涵蓋 43 題 Easy 與 2 題 Medium，統一依 Pattern 編排；#19 和 #61 收錄於鏈結串列筆記並標示難度。

## Pattern 是什麼？

Pattern 是可以在不同題目重用的解題思路。例如，#26 用兩個位置完成原地去重，#125 用兩端位置檢查回文；兩題都使用雙指標，但指標的意義與移動條件不同。

辨認 Pattern 時，先讀輸入限制、輸出要求與可維持的不變條件，再選方法。「陣列」是資料型別，不表示一定適合 sliding window；「有序」也可能用合併、二分搜尋或相鄰比較。這裡採用適合本專案的教學分類，不宣稱存在唯一的 LeetCode Pattern 清單。

## 如何開始練習

每次練習選一題，先用小例子手算，再讀程式。讀完後，試著不看程式解釋「每一輪之後，哪些事情一定成立」。能說清楚不變條件，才比較容易處理邊界。

以 #26 為例，重點是 `nums[:k]` 始終是已處理區間的去重結果。測試因此需要驗證 k 和前綴內容，不需要檢查尾端是否清空。

1. 寫出輸入前提：有序嗎？允許空值嗎？能否修改輸入？
2. 手算一般案例，再選一個容易弄錯的邊界。
3. 讀目前解法，標出狀態、更新規則和停止條件。
4. 跑該題測試，確認測試在比較值、順序，還是節點身分。
5. 嘗試改進前，先記錄原解法的時間與空間成本。

```bash
poetry run pytest tests/array/test_lc_026_remove_duplicates_from_sorted_array.py -q
```
